## 一、复杂度、递归与 C++ 基础

### 1.1 时间复杂度与空间复杂度

常见复杂度（从小到大）：

$$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(2^n) < O(n!)$$

**分析规则：**

- 只看最高阶项
- 循环折半 → $O(\log n)$
- 嵌套循环 → 乘积
- 递归 → 递归树 / 主定理

### 1.2 递归复杂度与主定理

对于 $T(n) = aT(n/b) + O(n^d)$：

- 若 $d < \log_b a$，则 $T(n) = O(n^{\log_b a})$
- 若 $d = \log_b a$，则 $T(n) = O(n^d \log n)$
- 若 $d > \log_b a$，则 $T(n) = O(n^d)$

**示例：归并排序**

```cpp
// T(n) = 2T(n/2) + O(n) → O(n log n)
void mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);
    merge(a, l, mid, r);
}
```

`pair` 使用字典序比较：先比较 `first`，只有 `first` 相等时才比较 `second`。因此默认规则是“`first` 升序，`second` 升序”。

**自定义比较器 cmp**

比较器 `cmp(a, b)` 的含义是：如果 `a` 应该排在 `b` 前面，就返回 `true`。比较器必须满足严格弱序，尤其不能写成 `a <= b`；相等时应返回 `false`。

```cpp
bool cmp(pair<int, int>& a, pair<int, int>& b) {
    if (a.first != b.first) return a.first < b.first;  // first 升序
    return a.second < b.second;                         // second升序
}

sort(vp.begin(), vp.end(), cmp);
```

### 1.4 高级排序方法

**lambda 排序法**

lambda 适合只使用一次的排序规则，代码最短，也是竞赛中最常用的写法。

```cpp
sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;  // 降序：a 应排在 b 前面
});
```

如果需要修改第二关键字的顺序，就要提供自定义比较器。例如“`first` 升序，`second` 降序”：

```cpp
sort(vp.begin(), vp.end(), [](pair<int, int>& a,pair<int, int>& b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;
});
```

**结构体重载 operator<**
如果一种类型需要反复使用同一套默认排序规则，可以在结构体中重载 `operator<`。下面按 `x` 升序排序；如果 `x` 相等，再按 `y` 升序排序。
```cpp
struct Node {
    int x, y;

    bool operator<(const Node& other) const {
        if (x != other.x) return x < other.x;
        return y < other.y;
    }
};

vector<Node> nodes;
sort(nodes.begin(), nodes.end());
```

如果只想临时改变规则，优先使用 `sort` 的第三个参数，而不是修改结构体的默认顺序。

```cpp
    int m = matrix.size(), n = matrix[0].size();
    int top = 0, bottom = m - 1, left = 0, right = n - 1;
    vector<int> res;

        for (int i = top; i <= bottom; i++) res.push_back(matrix[i][right]);
```

```cpp
void setZeroes(vector<vector<int>>& matrix) {

    bool row0 = false, col0 = false;
```

### 3.1 快速排序

```cpp
void quickSort(vector<int>&a, int l, int r) {
    if (l >= r) return;                     // 递归终止，一个元素别排序了

    int pivot = a[l];                       // 取第一个数为基准，同时挖坑
    int i = l, j = r;
    while (i < j) {
        while (i < j && a[j] >= pivot) j--; // 从右找小于pivot的数
        if (i < j) {a[i] = a[j]; i++;}           // 填左坑，右坑出现

        while (i < j && a[i] <= pivot) i++; // 从左找大于pivot的数
        if (i < j) {a[j] = a[i]; j--;}           // 填右坑，左坑出现
    }
    a[i] = pivot;                           // 结束的时候i=j

    quickSort(a, l, i - 1);                 // 递归左半
    quickSort(a, i + 1, r);                 // 递归右半
}
```

### 3.3 快速选择（第 K 小元素）O(n)

快速排序每次寻找pivot的本质：**确定pivot的最终归宿位置（即它在有序数组中的绝对下标）**。通过一次分区，我们把数组搅动成“左小右大”的格局，基准元素就坐到了它永远不变的那个“宝座”上。至于排名，是这个位置的自然结果。

分区结束后，对于基准位置 `i`，保证：

- 左侧所有元素 **都小于等于** `pivot`（具体是 `<` 还是 `<=` 取决于代码实现）
- 右侧所有元素 **都大于等于** `pivot`
  **关键结论**：基准元素 `a[i]` 就是整个数组**第 `i-l+1` 小**（在 `[l, r]` 区间内）的元素。

**快速选择的递推逻辑**
每次分区后，目标元素（第k小）的归宿只有三种可能：

- 正好是基准 `a[i]`（命中）
- 在左半区（因为左半区所有元素都排在基准前面）
- 在右半区（因为右半区所有元素都排在基准后面）
  于是，我们只需要**递归地处理可能包含目标的那半个区间**，另一个区间被彻底丢弃，这就是“剪枝”的精髓。

```cpp
// 注意：k 是 0-based 索引（即第 1 小传入 0，第 k 小传入 k-1）
int quickSelect(vector<int>& a, int l, int r, int k) {
    if (l == r) return a[l];

    int pivot = a[l];     // 基准值，同时 a[l] 成为第一个坑
    int i = l, j = r;
    while (i < j) {
        while (i < j && a[j] >= pivot) j--; // 从右找小于pivot的数
        if (i < j) {a[i] = a[j]; i++;}           // 填左坑，右坑出现

        while (i < j && a[i] <= pivot) i++; // 从左找大于pivot的数
        if (i < j) {a[j] = a[i]; j--;}           // 填右坑，左坑出现
    }
    a[i] = pivot;                           // 结束的时候i=j

    // 根据基准位置决定递归方向（只递归一侧）
    if (i == k) return a[i];
    else if (i > k) return quickSelect(a, l, i - 1, k);//在左半区间寻找
    else return quickSelect(a, i + 1, r, k);//在右半区间寻找
}
```

### 3.6 二分查找右边界

```cpp
int upperBound(vector<int>& a, int target) {
    int l = -1, r = a.size() - 1;     // 左开右闭 (l, r]
    while (l < r) {
        int mid = l + (r - l + 1) / 2; // 向上取整（偏右）
        if (a[mid] <= target) l = mid;  // 等于时也向右收缩
        else r = mid - 1;
    }
    // 结束时 l == r
    if (l == -1 || a[l] != target) return -1; // 未找到
    return l; // 返回右边界（最后一个等于 target 的位置）
}
```

### 3.11 滑动窗口（最长无重复子串）

```cpp
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> cnt;
    int ans = 0;
    for (int l = 0, r = 0; r < s.size(); r++) {
        cnt[s[r]]++;
        while (cnt[s[r]] > 1) cnt[s[l++]]--;
        ans = max(ans, r - l + 1);
    }
    return ans;
}
```

```cpp
string minWindow(string s, string t) {
    unordered_map<char, int> need, window;
    for (char c : t) need[c]++;
    int valid = 0, start = 0, len = INT_MAX;
    for (int l = 0, r = 0; r < s.size(); r++) {
        char c = s[r];
```

### 5.8 LRU 缓存（用哈希索引实现对双向链表的O(1)查找和删除）

```cpp
class LRUCache {
    int cap;
    list<pair<int,int>> cache;  // (key, value)
    unordered_map<int, list<pair<int,int>>::iterator> mp;
public:
    LRUCache(int capacity) : cap(capacity) {}
    int get(int key) {
        if (!mp.count(key)) return -1;
        auto it = mp[key];
        auto node = *it;       // 先保存节点内容
        cache.erase(it);       // 删除旧节点（原迭代器随之失效）
        cache.push_front(node); // 重新插入到表头，表示最近使用
        mp[key] = cache.begin();
        return node.second;
    }
    void put(int key, int value) {
        if (mp.count(key)) {
            auto it = mp[key];
            cache.erase(it);
            cache.push_front({key, value});
            mp[key] = cache.begin();
        } 
        else {
            if (cache.size() == cap) {
                mp.erase(cache.back().first);
                cache.pop_back();
            }
            cache.push_front({key, value});
            mp[key] = cache.begin();
        }
    }
};
```

- **哈希表** `mp`：保存 `key → 链表节点迭代器`，负责在 `O(1)` 时间内找到节点。
- **双向链表** `cache`：负责维护使用顺序；表头是最近使用的节点，表尾是最久未使用、容量满时要淘汰的节点。
- 不使用 `list::splice` 时，访问旧节点要先保存数据，再 `erase` 旧节点、`push_front` 新节点，并更新哈希表中的迭代器；这些链表操作仍然都是 `O(1)`。

### 6.3 由前序遍历和中序遍历构造二叉树

这道题的关键不是“把两个数组逐个比较”，而是利用两种遍历各自提供的信息：

- 前序遍历的第一个元素一定是当前子树的根节点；
- 在中序遍历中找到根节点后，左边部分就是左子树，右边部分就是右子树；
- 左子树的节点数量决定了前序遍历中左右子树区间的切分位置。

下面保留原来的线性查找写法：每次递归都在当前中序区间中寻找根节点的位置。真正需要理清的是找到位置 `i` 之后，前序和中序两个区间怎样同步切分。

```cpp
class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = preorder.size();
        return build(preorder, 0, n - 1, inorder, 0, n - 1);
    }

    TreeNode* build(vector<int>& preorder, int l1, int r1,
                    vector<int>& inorder, int l2, int r2) {
        if (l1 > r1) return nullptr;

        int gen = preorder[l1];
        int i;
        for (i = l2; i <= r2; i++) {
            if (inorder[i] == gen) break;
        }

        TreeNode* root = new TreeNode(gen);
        root->left = build(preorder, l1 + 1, l1 + i - l2,
                           inorder, l2, i - 1);
        root->right = build(preorder, l1 + i - l2 + 1, r1,
                            inorder, i + 1, r2);
        return root;
    }
};
```

递归区间的含义如下：`l1..r1` 是当前子树在前序数组中的范围，`l2..r2` 是当前子树在中序数组中的范围。根节点在中序数组中的位置是 `i`，所以左子树节点数为 `leftSize = i - l2`。

- 左子树在中序中的范围是 `[l2, i - 1]`，共有 `i - l2` 个节点。因此它在前序中从根节点后面开始，范围是 `[l1 + 1, l1 + i - l2]`。
- 右子树紧接在左子树之后，所以它在前序中的范围从 `l1 + i - l2 + 1` 开始，一直到 `r1`；在中序中的范围是 `[i + 1, r2]`。

因此下面两行正好把同一棵子树在两种遍历中的区间对应起来：

```cpp
root->left = build(preorder, l1 + 1, l1 + i - l2, inorder, l2, i - 1);
root->right = build(preorder, l1 + i - l2 + 1, r1, inorder, i + 1, r2);
```

当前写法在每个递归层都要扫描中序区间寻找 `i`，时间复杂度最坏为 $O(n^2)$；递归栈的额外空间复杂度为 $O(n)$。如果用哈希表预先记录中序位置，才可以把查找根节点位置降为 $O(1)$。

![由前序遍历和中序遍历构造二叉树的递归过程示意图](./assets/build-tree-preorder-inorder.png)

图中示例：前序遍历为 `3, 9, 20, 15, 7`，中序遍历为 `9, 3, 15, 20, 7`。先取前序第一个元素 `3` 作为根，再用它在中序中的位置切出左子树和右子树，之后对两个区间重复相同过程。

### 7.7 Dijkstra（单源最短路，含堆优化，不可负权）

```c++
vector<int> dijkstra(int start, vector<vector<pair<int,int>>>& adj,int n) {
    vector<int> dist(n, INT_MAX);
    dist[start] = 0;
    
    vector<bool> visited(n, false);   // 记录每个顶点是否已确定最短距离

        int u = -1;
        int minDist = INT_MAX;
        for (int i = 0; i < n; ++i) {
            if (!visited[i] && dist[i] < minDist) {
                minDist = dist[i];
                u = i;
            }

        // 如果 u 仍然为 -1，说明剩余顶点不可达（图不连通），提前结束

        // 2. 用 u 的邻接边松弛

                dist[v] = dist[u] + w;
            }
        }
    }
    return dist;
```

```cpp
vector<int> dijkstra(int start, vector<vector<pair<int,int>>>& adj,int n) {                     
    vector<int> dist(n, INT_MAX);
    dist[start] = 0;            
    //为了方便排序，把距离放在前面的第一个字段
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, start});        

    //主循环：不断从堆中取出“当前距离最小”的顶点
    while (!pq.empty()) {
        // 取出当前已知的距离最小的顶点
        auto [d, u] = pq.top(); 
        pq.pop();
        //这个u节点的最短距离已经被确定了，这个d就是之前没被清理掉的垃圾
        if (d > dist[u]) continue;
		
        for (auto &[to, cost] : adj[u]) {
            // 借助当前顶点更新到其他顶点的最短距离，这步没区别
            if (dist[u] + cost < dist[to]) {
                dist[to] = dist[u] + cost;          // 更新最短距离
                pq.push({dist[to], to});          // 知道了到某个顶点的最短距离，加入！
            }
        }
    }

    return dist;
}
```

```cpp
int bellmanFord(vector<Edge>& edges, int n, int start) {
    vector<int> dist(n, INT_MAX);
    dist[start] = 0;
    for (int i = 0; i < n - 1; i++)
        for (auto& e : edges)

                dist[e.v] = min(dist[e.v], dist[e.u] + e.w);
```

### 7.10 Prim（最小生成树，含堆优化）

图仍然使用邻接表。`minEdge[i]` 表示顶点 `i` 连接到当前生成树所需的最小边权。

未堆优化：

```cpp
int prim(vector<vector<pair<int,int>>>& adj, int n) {
    vector<int> minEdge(n, INT_MAX);
    vector<bool> visited(n, false);
    minEdge[0] = 0;                      // 从顶点 0 开始
    int ans = 0;
    // 每轮确定一个加入最小生成树的顶点
    for (int count = 0; count < n; count++) {
        // 1. 在所有未访问顶点中，选 minEdge 最小的顶点 u
        int u = -1;
        for (int i = 0; i < n; i++)
            if (!visited[i] && (u == -1 || minEdge[i] < minEdge[u]))
                u = i;
        // 找不到可加入的顶点，说明原图不连通
        if (u == -1 || minEdge[u] == INT_MAX) return -1;

        visited[u] = true;
        ans += minEdge[u];
        // 2. 用 u 的邻接边更新其他顶点连入生成树的最小边权
        for (auto [v, w] : adj[u])
            if (!visited[v] && w < minEdge[v])
                minEdge[v] = w;          // 注意：这里是 w，不是 minEdge[u] + w
    }
    return ans;
}
```

堆优化版：

```cpp
int prim(vector<vector<pair<int,int>>>& adj, int n) {
    vector<bool> visited(n, false);

    // 小根堆存储（连入生成树的边权, 顶点）
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, 0});

    int ans = 0, count = 0;
    while (!pq.empty()) {
        auto [w, u] = pq.top();
        pq.pop();

        // 同一顶点可能由多条边入堆，已经加入生成树就跳过
        if (visited[u]) continue;

        visited[u] = true;
        ans += w;
        count++;

        // 把从生成树通向未访问顶点的候选边加入堆
        for (auto [v, edgeWeight] : adj[u])
            if (!visited[v])
                pq.push({edgeWeight, v});
    }

    return count == n ? ans : -1;        // 不连通时不存在生成树
}
```

```cpp
int knapsackMultiple_2D(vector<int>& w, vector<int>& v,
                        vector<int>& s, int W) {
    int n = w.size();
    // dp[i][j]：只看前 i 种物品，容量为 j 时的最大价值
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

                dp[i][j] = max(dp[i][j],
                               dp[i - 1][j - k * w[i - 1]]
                               + k * v[i - 1]);
            }
        }
    }
    return dp[n][W];
}
```

关键：枚举第 `i` 种物品选 `k` 个，再从上一行查剩余容量。这个版本最直观，但需要多枚举一层 `k`。

**一维 DP（二进制拆分优化）：**

```cpp
int knapsackMultiple(vector<int>& w, vector<int>& v, vector<int>& s, int W) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < w.size(); i++) {
        int k = 1;
        while (s[i] > 0) {
            int cnt = min(k, s[i]);
            for (int j = W; j >= w[i] * cnt; j--)
                dp[j] = max(dp[j], dp[j - w[i] * cnt] + v[i] * cnt);
            s[i] -= cnt; k *= 2;
        }
    }
    return dp[W];
}
```

```cpp
int stoneMerge(vector<int>& a) {
    int n = a.size();
    vector<int> pre(n + 1, 0);
    for (int i = 0; i < n; i++) pre[i+1] = pre[i] + a[i];
    vector<vector<int>> dp(n, vector<int>(n, 0));

        for (int i = 0; i + len - 1 < n; i++) {

        }

}
```

### 10.13 旅行商（状态压缩 DP）

```cpp
int tsp(vector<vector<int>>& dist) {
    int n = dist.size();
    vector<vector<int>> dp(1 << n, vector<int>(n, INT_MAX));
    dp[1][0] = 0;
    for (int mask = 1; mask < (1 << n); mask++)
        for (int i = 0; i < n; i++)
            if (dp[mask][i] < INT_MAX)
                for (int j = 0; j < n; j++)
                    if (!(mask & (1 << j)))
                        dp[mask | (1 << j)][j] = min(dp[mask | (1 << j)][j],
                                                     dp[mask][i] + dist[i][j]);
    int ans = INT_MAX;
    for (int i = 1; i < n; i++)
        ans = min(ans, dp[(1<<n)-1][i] + dist[i][0]);
    return ans;
}
```

```cpp
int kmp(string& s, string& p) {
    auto nxt = getNext(p);
    int n = s.size(), m = p.size();
    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && s[i] != p[j]) j = nxt[j - 1];
        if (s[i] == p[j]) j++;
```

```cpp
Matrix mul(Matrix& A, Matrix& B, long long mod) {
    int n = A.size();
    Matrix C(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++)
            for (int j = 0; j < n; j++)
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % mod;
    return C;
}
Matrix matPow(Matrix A, long long b, long long mod) {
    int n = A.size();
    Matrix res(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++) res[i][i] = 1;
    while (b) {
        if (b & 1) res = mul(res, A, mod);
        A = mul(A, A, mod);
        b >>= 1;
    }
    return res;
```

```cpp
// 求 [1, n] 中能被集合 A 中至少一个数整除的个数
long long inclusionExclusion(int n, vector<int>& A) {
    long long ans = 0;
    int m = A.size();
    for (int mask = 1; mask < (1 << m); mask++) {
        long long lcm = 1;
        int bits = 0;
        for (int i = 0; i < m; i++)
            if (mask & (1 << i)) {
                bits++;
                lcm = lcm / gcd(lcm, A[i]) * A[i];
                if (lcm > n) break;
            }
        if (bits % 2 == 1) ans += n / lcm;
        else ans -= n / lcm;
    }
    return ans;
}
```

```cpp
vector<double> gauss(vector<vector<double>>& a) {
    int n = a.size();
    for (int i = 0; i < n; i++) {
        int r = i;
        for (int j = i + 1; j < n; j++)
            if (fabs(a[j][i]) > fabs(a[r][i])) r = j;
        swap(a[i], a[r]);
        for (int j = i + 1; j <= n; j++) a[i][j] /= a[i][i];
        a[i][i] = 1;
        for (int k = 0; k < n; k++)
            if (k != i)
                for (int j = i + 1; j <= n; j++)
                    a[k][j] -= a[k][i] * a[i][j];
    }
    vector<double> ans(n);
    for (int i = 0; i < n; i++) ans[i] = a[i][n];
    return ans;
}
```
