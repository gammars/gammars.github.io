## 五、技术栈补充建议

### 核心必须掌握的

| 知识点                           | 优先级 | 学习建议                          |
| :------------------------------- | :----- | :-------------------------------- |
| Python 异步编程（asyncio/await） | ⭐⭐⭐    | 理解事件循环、协程、Future        |
| FastAPI                          | ⭐⭐⭐    | 适合 Agent 服务开发，SSE 流式输出 |
| Redis                            | ⭐⭐     | 会话存储、限流、缓存              |
| MCP 协议                         | ⭐⭐     | Agent 工具调用标准协议            |

### Agent 框架理解

| 概念             | 理解要点                                                |
| :--------------- | :------------------------------------------------------ |
| LangChain Chain  | 链式调用，把多个操作串起来                              |
| LangGraph Graph  | State（状态）+ Node（节点）+ Edge（边），更灵活的状态机 |
| Agent 状态持久化 | checkpoint、对话历史存储、中断恢复                      |
| 多 Agent 通信    | 消息队列（Kafka/RocketMQ）、共享状态                    |

### 流式输出

| 技术      | 用途                             |
| :-------- | :------------------------------- |
| SSE       | 服务端推送，单向，适合 chat 场景 |
| WebSocket | 双向通信，更复杂但更强大         |

### RAG 相关

| 问题               | 说明                                                   |
| :----------------- | :----------------------------------------------------- |
| Milvus vs ChromaDB | Milvus 支持分布式、更大规模向量；ChromaDB 轻量本地开发 |
| 图片/表格 RAG      | 用多模态模型（GPT-4V）或专门解析库                     |
| Pydantic 校验      | 约束 Tool Call 参数，确保大模型输出符合 schema         |
