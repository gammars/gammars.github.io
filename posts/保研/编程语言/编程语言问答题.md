## 1. 指针 vs 引用

### 问：指针和引用有什么区别？
**答：**
- **指针**：是一个变量，存放的是另一个变量的**地址**。
    - 可以为空（`int *p = nullptr;`）。
    - 可以改变指向（今天指向 `a`，明天指向 `b`）。
    - 使用时需要**解引用**（`*p`）。
- **引用**：是变量的**别名**，定义后即与原变量绑定。
    - 必须初始化，不能引用空对象。
    - 一旦绑定，不能改为其他变量的引用。
    - 使用起来和普通变量一样，无需解引用。

- **示例：**
    ```cpp
    int a = 10, b = 20;
    int *p = &a; // p 指向 a
    p = &b;      // p 可以改为指向 b

    int &r = a;  // r 是 a 的引用
    r = b;       // 不是让 r 引用 b，而是把 b 的值赋给 a
    ```

> **背诵：** 指针是存地址的变量，可以为空，可以改变指向；引用是变量别名，必须初始化，绑定后不能改变引用对象。指针要解引用，引用像普通变量一样使用。

## 2. 浅拷贝 vs 深拷贝

### 问：浅拷贝和深拷贝有什么区别？
**答：**
- **浅拷贝**：只复制对象中的普通成员值。若对象内部有指针，浅拷贝只复制指针地址（即复制指针本身），**不复制**指针指向的真实资源。这会导致两个对象的指针指向同一块内存，容易引发**重复释放**和**野指针**问题。
- **深拷贝**：不仅复制指针地址，还会**重新申请一块新的内存**，并将原内容复制过去。这样两个对象各自拥有独立资源，互不影响。

- **示例：** 类 `String` 中有 `char *name` 成员。
    - 浅拷贝：两个对象的 `name` 指向同一个字符串。
    - 深拷贝：为新对象重新申请空间，复制字符串内容。

> **背诵：** 浅拷贝复制地址，多个对象共享同一块资源，容易重复释放和野指针；深拷贝重新申请内存并复制内容，每个对象独立管理自己的资源。

## 3. 编译执行过程（预处理、编译、汇编、链接）

### 问：C/C++ 程序从源代码到运行经历哪些过程？
**答：** C/C++ 程序通常经历四个阶段：
1.  **预处理**：处理 `#include`、`#define`、条件编译等。例如，展开头文件内容，替换宏定义。
2.  **编译**：将预处理后的代码翻译成**汇编代码**，并进行词法、语法、语义分析和优化。
3.  **汇编**：将汇编代码转换成**机器指令**，生成目标文件（`.o` 或 `.obj`）。
4.  **链接**：将多个目标文件和库文件组合，解析外部符号引用（如 `printf` 的实现），生成最终**可执行文件**。

> **背诵：** C/C++ 编译执行过程是：预处理 → 编译 → 汇编 → 链接。预处理处理宏和头文件，编译生成汇编，汇编生成目标文件，链接生成可执行文件。

## 4. C++ 运算符重载

### 问：什么是 C++ 运算符重载？有什么作用？
**答：** 运算符重载是给已有运算符赋予新的含义，让**自定义类型**也能像基本类型一样使用运算符（如 `+`、`-`、`==`）。

- **示例：** 为复数类 `Complex` 重载 `+` 运算符。
    ```cpp
    class Complex {
    public:
        int real, imag;
        Complex(int r, int i) : real(r), imag(i) {}
        Complex operator+(const Complex& other) {
            return Complex(real + other.real, imag + other.imag);
        }
    };
    Complex c1(1,2), c2(3,4);
    Complex c3 = c1 + c2; // 可直接相加
    ```

**注意：** 运算符重载**不能改变**运算符的优先级和结合性，也**不能创建**新的运算符。

> **背诵：** 运算符重载是让自定义类型也能使用已有运算符。它提高代码可读性，但不能改变运算符优先级、结合性，也不能创建新运算符。

## 5. C++ 多态实现方式（静态与动态）

### 问：C++ 多态是怎么实现的？
**答：** C++ 多态分为**静态多态**和**动态多态**。
- **静态多态**：在**编译期间**确定，主要包括**函数重载、运算符重载、模板**。
- **动态多态**：在**运行期间**确定，主要依靠**继承**和**虚函数**实现。当使用父类指针或引用指向子类对象时，调用虚函数会根据对象的**真实类型**决定执行哪个版本。

- **动态多态示例：**
    ```cpp
    class Animal {
    public:
        virtual void speak() { cout << "Animal" << endl; }
    };
    class Dog : public Animal {
    public:
        void speak() override { cout << "Dog" << endl; }
    };
    Animal* p = new Dog();
    p->speak(); // 输出 "Dog"
    ```
- **底层原理：** 动态多态依靠**虚函数表（vtable）** 和**虚函数指针（vptr）**。含有虚函数的类对象中有一个虚函数指针，指向该类的虚函数表。运行时通过虚函数表找到真正要调用的函数。

> **背诵：** C++ 多态分为静态多态和动态多态。静态多态包括函数重载、运算符重载、模板；动态多态通过继承、虚函数、父类指针或引用实现，底层依靠虚函数表。

## 6. Java vs C++ vs C 区别

### 问：Java、C++、C 有什么区别？
**答：**

| 特性 | C | C++ | Java |
| :--- | :--- | :--- | :--- |
| **编程范式** | 面向过程 | 面向过程 + 面向对象 + 泛型 | 面向对象 |
| **内存管理** | 手动管理（`malloc/free`） | 手动管理（`new/delete`） | 自动垃圾回收（GC） |
| **编译与运行** | 直接编译为机器码 | 直接编译为机器码 | 编译为字节码，由 JVM 解释/编译执行 |
| **跨平台性** | 差（依赖具体平台） | 差（依赖具体平台） | 好（JVM 屏蔽底层差异） |
| **指针** | 支持 | 支持 | 不直接暴露（内部使用引用） |
| **典型应用** | 操作系统、嵌入式 | 游戏、高性能计算、系统软件 | 后端、企业级应用、Android |

> **背诵：** C 面向过程，底层高效，手动管理内存；C++ 兼容 C，支持面向对象和泛型，性能强但复杂；Java 面向对象，运行在 JVM 上，跨平台，有垃圾回收机制。

## 7. Java 垃圾回收算法

### 问：Java 常见垃圾回收算法有哪些？
**答：** Java 垃圾回收（GC）负责自动回收不再使用的对象。判断对象是否可回收，主要使用**可达性分析**：从 **GC Roots** 出发，无法被访问到的对象视为不可达，可被回收。

- **常见算法：**
    1.  **标记-清除**：标记所有可达对象，再清除未标记对象。缺点：产生**内存碎片**。
    2.  **复制算法**：将内存分为两块，每次只使用一块。回收时将存活对象复制到另一块，再清空原区域。优点：效率高；缺点：**浪费一半空间**。
    3.  **标记-整理**：标记存活对象后，将其向一端移动，再清理边界外内存。优点：**减少内存碎片**。
    4.  **分代收集**：根据对象生命周期将堆分为**新生代**和**老年代**。
        - 新生代：朝生夕死，常用**复制算法**。
        - 老年代：存活时间长，常用**标记-清除**或**标记-整理**。

> **背诵：** Java 垃圾回收通过可达性分析判断对象是否存活。常见算法有标记-清除、复制、标记-整理、分代收集。新生代常用复制算法，老年代常用标记-清除或标记-整理。

## 8. JVM 内存管理

### 问：JVM 内存区域有哪些？
**答：** JVM 运行时内存主要分为以下区域：
- **程序计数器**：记录当前线程执行的字节码指令地址。**线程私有。**
- **虚拟机栈**：存储 Java 方法调用的栈帧（含局部变量表、操作数栈、返回地址等）。**线程私有。**
- **本地方法栈**：为 `native` 方法（非 Java 实现）服务。**线程私有。**
- **堆（Heap）**：存放**对象实例**，是垃圾回收的主要区域。**线程共享。**
- **方法区**：存储类信息、常量、静态变量、即时编译后的代码等。**线程共享**。JDK 8 后的实现主要是**元空间（Metaspace）**。

> **背诵：** JVM 内存包括程序计数器、虚拟机栈、本地方法栈、堆、方法区。栈管方法调用，堆放对象实例，方法区放类信息。程序计数器、虚拟机栈、本地方法栈是线程私有的；堆和方法区是线程共享的。

## 9. 全局变量利弊

### 问：全局变量有什么优点和缺点？
**答：**
- **优点：** 使用方便，可在多个函数间共享数据，无需频繁通过参数传递。
- **缺点：**
    1.  增加程序**耦合度**，难以维护。
    2.  **生命周期长**，占用内存时间长。
    3.  多线程环境下，易产生**数据竞争**。
    4.  **调试困难**，难以追踪被修改的位置。

> **背诵：** 全局变量优点是共享方便，缺点是耦合度高、生命周期长、容易被误改、多线程下不安全、调试困难。实际开发中应尽量减少全局变量。

## 10. C++ 异常机制

### 问：C++ 异常机制是什么？
**答：** C++ 异常机制用于处理运行时错误，主要由 `try`、`throw`、`catch` 三部分组成。
- `try`：包裹可能出错的代码。
- `throw`：抛出异常。
- `catch`：捕获并处理异常。

- **示例：**
    ```cpp
    try {
        if (b == 0) throw "division by zero";
        cout << a / b << endl;
    } catch (const char* msg) {
        cout << msg << endl;
    }
    ```
- **标准异常：** `std::exception`、`std::runtime_error`、`std::bad_alloc` 等。
- **优点：** 将正常逻辑与错误处理逻辑分离，代码更清晰。
- **缺点：** 有一定性能开销，不当使用会使控制流变复杂。

> **背诵：** C++ 异常机制由 try、throw、catch 组成。try 放可能出错的代码，throw 抛出异常，catch 捕获异常。它用于处理运行时错误，使正常逻辑和错误处理分离。

## 11. const 关键字

### 问：C++ 中 const 有什么作用？
**答：** `const` 表示**只读**，用于限制变量、指针、函数参数、成员函数等不能被修改。

- **常见用法：**
    - **定义常量：** `const int x = 10;`（`x` 不可修改）
    - **指向常量的指针：** `const int* p = &x;`（不能通过 `p` 修改指向的值，但 `p` 可指向其他变量）
    - **常量指针：** `int* const p = &a;`（`p` 的指向不可变，但可通过 `p` 修改指向的值）
    - **指向常量的常量指针：** `const int* const p = &a;`（指向和值都不可变）
    - **修饰函数参数：** 防止函数内部误修改参数。
    - **修饰成员函数：** `string getName() const;` 表示该函数**不会修改**对象的成员变量。

> **背诵：** const 表示只读。修饰变量表示不能改值；修饰指针要看 const 在 `*` 左边还是右边。const 在 `*` 左边，值不能改；在 `*` 右边，指针不能改。成员函数后加 const 表示不修改对象状态。

## 12. int vs enum

### 问：int 和 enum 有什么区别？
**答：**
- **`int`**：普通整数类型，可表示任意整数值。
- **`enum`（枚举）**：一组**命名的整数常量**，用于增强代码可读性（如状态码用 `RUNNING`、`STOPPED` 比直接用 0、1、2 更清晰）。

- **C++ 中的 `enum` 与 `enum class`：**
    - 普通 `enum`：与整数关系近，类型安全性较弱。
    - `enum class`（C++11）：**强类型枚举**，不能隐式转换为整数，需通过 `Color::RED` 访问，类型更安全。
    ```cpp
    enum class Color { RED, GREEN, BLUE };
    Color c = Color::RED;
    ```

> **背诵：** int 是普通整数，enum 是一组命名整数常量。枚举能提高代码可读性。C++ 中 enum class 比普通 enum 类型更安全。

## 13. 指针类型

### 问：常见指针类型有哪些？
**答：**
- **普通指针**：存放变量地址，如 `int* p;`
- **空指针**：不指向任何有效对象，如 `int* p = nullptr;`
- **野指针**：指向非法或已释放内存的指针，使用危险。
- **悬空指针**：指针原指向的对象已被释放，但指针未置空。
- **常量指针**：指针本身不能改变指向，如 `int* const p = &a;`
- **指向常量的指针**：不能通过指针修改指向的值，如 `const int* p = &a;`
- **函数指针**：指向函数的指针，如 `int (*fp)(int, int);`
- **二级指针**：指向指针的指针，如 `int** pp;`
- **`void` 指针**：通用指针，可指向任意类型，使用前需强制类型转换，如 `void* p;`

> **背诵：** 常见指针有普通指针、空指针、野指针、悬空指针、常量指针、指向常量的指针、函数指针、二级指针、void 指针。最危险的是野指针和悬空指针，使用前要注意初始化、释放后置空。

## 14. 数组指针 vs 指针数组

### 问：数组指针和指针数组有什么区别？
**答：**

| 名称 | 本质 | 写法 | 含义 |
| :--- | :--- | :--- | :--- |
| **数组指针** | **指针**（指向数组） | `int (*p)[3];` | `p` 是一个指针，指向一个包含 3 个 `int` 的数组。 |
| **指针数组** | **数组**（元素为指针） | `int* p[3];` | `p` 是一个数组，包含 3 个元素，每个元素都是 `int*` 指针。 |

**判断技巧：** 看括号和优先级。
- `int (*p)[3];`：`p` 先与 `*` 结合，说明 `p` 是**指针**，指向数组 → **数组指针**。
- `int* p[3];`：`p` 先与 `[3]` 结合，说明 `p` 是**数组**，元素类型为 `int*` → **指针数组**。

> **背诵：**
> - 数组指针：指向数组的指针，本质是**指针**：`int (*p)[3]`。
> - 指针数组：存放指针的数组，本质是**数组**：`int* p[3]`。
> - 记忆口诀：**数组指针看"指针"，指针数组看"数组"。**

## 15. 总背诵版（最终总结）

- **指针 vs 引用**：指针是存地址的变量，可为空、可变指向；引用是别名，必须初始化、不可变。
- **浅拷贝 vs 深拷贝**：浅拷贝复制地址，共享资源；深拷贝复制内容，独立资源。
- **编译过程**：预处理 → 编译 → 汇编 → 链接。
- **运算符重载**：让自定义类型使用运算符，提高可读性。
- **C++ 多态**：静态（重载、模板）和动态（继承、虚函数、虚函数表）。
- **C vs C++ vs Java**：C 面向过程；C++ 面向对象+泛型；Java 运行在 JVM，有 GC。
- **Java GC**：可达性分析；算法：标记-清除、复制、标记-整理、分代收集。
- **JVM 内存**：程序计数器、虚拟机栈、本地方法栈（私有）；堆、方法区（共享）。
- **全局变量**：共享方便，但耦合高、生命周期长、多线程不安全。
- **异常机制**：`try`、`throw`、`catch`。
- **`const`**：只读；修饰指针看位置：左值右指。
- **`enum`**：命名整数常量；`enum class` 更安全。
- **数组指针 vs 指针数组**：`int (*p)[3]` 是数组指针（指针）；`int* p[3]` 是指针数组（数组）。
