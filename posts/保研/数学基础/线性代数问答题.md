# 1. 矩阵的秩与满秩含义

## 面试版回答

矩阵的秩表示矩阵中**线性无关的行向量或列向量的最大个数**。行秩和列秩总是相等，所以统一称为矩阵的秩。

对于 (A\in \mathbb R^{m\times n})：

[
\operatorname{rank}(A)\leq \min(m,n)
]

如果

[
\operatorname{rank}(A)=\min(m,n)
]

就称 (A) 是**满秩矩阵**。

对于 (n\times n) 方阵，满秩就是

[
\operatorname{rank}(A)=n
]

这等价于矩阵可逆，也等价于行列式不为 0。

---

## 详细理解

例如：

[
A=
\begin{bmatrix}
1&2\
2&4
\end{bmatrix}
]

第二行是第一行的两倍，因此只有一行是独立的：

[
\operatorname{rank}(A)=1
]

它所能表示的线性变换实际上把二维空间“压”到了一条直线上。

而

[
A=
\begin{bmatrix}
1&0\
0&1
\end{bmatrix}
]

两个行向量、列向量都线性无关，因此

[
\operatorname{rank}(A)=2
]

是满秩矩阵。

### 秩的几个重要理解

**从列空间看：**

[
\operatorname{rank}(A)=\dim \operatorname{Col}(A)
]

也就是所有列向量能够张成的空间的维数。

**从线性映射看：**

如果

[
y=Ax
]

那么 rank 表示这个线性变换的**像空间维数**。

例如：

[
\mathbb R^3\rightarrow \mathbb R^2
]

最多只能得到二维的输出空间，所以一个 (2\times3) 矩阵最多 rank=2。

---

## 方阵满秩的超级重要等价条件

对于

[
A\in\mathbb R^{n\times n}
]

下面这些基本等价：

[
\operatorname{rank}(A)=n
]

[
\Longleftrightarrow \det(A)\neq0
]

[
\Longleftrightarrow A^{-1}\text{存在}
]

[
\Longleftrightarrow Ax=0\text{只有零解}
]

[
\Longleftrightarrow A\text{的列向量线性无关}
]

[
\Longleftrightarrow A\text{的行向量线性无关}
]

[
\Longleftrightarrow 0\text{不是A的特征值}
]

这是保研面试非常喜欢连续追问的一串。

---

### 老师可能追问

**Q：(3\times5) 矩阵满秩是多少？**

[
\boxed{3}
]

因为最大秩为 (\min(3,5)=3)。

**Q：(5\times3) 矩阵呢？**

最大也是 3。

但前者叫**满行秩**，后者叫**满列秩**。

# 2. 线性相关与线性无关

## 面试版回答

给定向量

[
v_1,v_2,\dots,v_n
]

如果存在一组**不全为零**的系数

[
k_1,k_2,\dots,k_n
]

使得

[
k_1v_1+k_2v_2+\cdots+k_nv_n=0
]

那么这些向量线性相关。

如果只有

[
k_1=k_2=\cdots=k_n=0
]

才能使线性组合等于零，那么这些向量线性无关。

---

## 本质是什么？

一句话：

> **线性相关意味着至少一个向量可以被其他向量线性表示。**

例如：

[
v_1=
\begin{bmatrix}1\0\end{bmatrix},
\quad
v_2=
\begin{bmatrix}0\1\end{bmatrix}
]

显然彼此不能表示，因此线性无关。

但如果加入：

[
v_3=
\begin{bmatrix}1\1\end{bmatrix}
]

有：

[
v_3=v_1+v_2
]

因此

[
v_1+v_2-v_3=0
]

存在非零系数，所以三个向量线性相关。

---

## 和矩阵有什么关系？

把这些向量作为矩阵的列：

[
A=[v_1,v_2,\cdots,v_n]
]

那么：

[
Ax=0
]

实际上就是：

[
x_1v_1+x_2v_2+\cdots+x_nv_n=0
]

所以：

**列向量线性无关**

[
\Longleftrightarrow Ax=0\text{只有零解}
]

[
\Longleftrightarrow \operatorname{rank}(A)=n
]

如果 (A) 有 (n) 列的话。

---

### 一个面试常见结论

在 (\mathbb R^n) 中：

* 超过 (n) 个向量一定线性相关；
* 最多只能有 (n) 个线性无关向量。

比如在二维空间中放三个向量，必然线性相关。

# 3. 向量空间与线性空间

这两个词在一般线性代数语境下**基本是同一个概念**：

> Vector Space = 向量空间 = 线性空间。

不要把它理解成“向量”和“线性空间”的区别。

---

## 面试版回答

线性空间是定义在某个数域 (F) 上的集合 (V)，其中定义了：

* 向量加法；
* 数乘；

并且对这两种运算满足封闭性以及结合律、交换律、分配律等公理。

例如：

[
\mathbb R^n
]

就是最典型的实数域上的线性空间。

---

## 关键理解

很多人误认为“向量”一定长这样：

[
\begin{bmatrix}
1\
2\
3
\end{bmatrix}
]

其实不是。

只要满足线性空间的公理，很多对象都可以被看作向量。

例如：

### 多项式空间

[
P_2={a+bx+cx^2}
]

也是一个线性空间。

例如：

[
1+x,\qquad x+x^2
]

都可以看作这个空间里的“向量”。

---

### 矩阵空间

所有 (2\times2) 实矩阵：

[
M_{2\times2}(\mathbb R)
]

本身也构成一个向量空间。

其维数是：

[
4
]

因为可以取基：

[
\begin{bmatrix}1&0\0&0\end{bmatrix},
\begin{bmatrix}0&1\0&0\end{bmatrix},
\begin{bmatrix}0&0\1&0\end{bmatrix},
\begin{bmatrix}0&0\0&1\end{bmatrix}
]

---

## 老师很可能追问

**Q：什么集合不构成线性空间？**

例如：

[
V={(x,y):x>0}
]

不是线性空间。

因为：

[
(1,0)\in V
]

但

[
-1(1,0)=(-1,0)\notin V
]

不满足数乘封闭性。

而且线性空间必须包含：

[
\boxed{0}
]

零向量。

---

# 4. 向量的基

## 面试版回答

一组向量如果同时满足：

1. **线性无关**
2. **能够张成整个向量空间**

那么就称这组向量为这个空间的一组基。

基可以理解为描述整个空间所需要的**最小的独立方向集合**。

---

例如二维空间：

[
\mathbb R^2
]

最常见的基为：

[
e_1=
\begin{bmatrix}1\0\end{bmatrix},
\quad
e_2=
\begin{bmatrix}0\1\end{bmatrix}
]

任何向量：

[
v=
\begin{bmatrix}x\y\end{bmatrix}
]

都可以唯一表示为：

[
v=xe_1+ye_2
]

---

## 基为什么要同时要求两个条件？

例如：

[
e_1,e_2,e_1+e_2
]

能张成 (\mathbb R^2)，但是它们线性相关，所以不是基。

只取：

[
e_1
]

线性无关，但是无法张成整个 (\mathbb R^2)，所以也不是基。

基要求：

> **既不少，也不冗余。**

---

## 维数

一个有限维线性空间的任意一组基，向量个数都相同。

这个数叫：

[
\dim V
]

例如：

[
\dim\mathbb R^3=3
]

---

## 和矩阵 rank 的关系

矩阵：

[
A=[a_1,a_2,\dots,a_n]
]

从列向量中找到最大线性无关组，它们就是：

[
\operatorname{Col}(A)
]

的一组基。

基向量个数就是：

[
\operatorname{rank}(A)
]

所以：

> **秩就是列空间或者行空间的维数。**

这个回答非常适合老师从第 1 题追到第 4 题。

---

# 5. 向量正交与矩阵正交

# 向量正交

## 面试版

对于两个向量 (x,y)，如果：

[
x^Ty=0
]

那么称两个向量正交。

几何上对应它们的夹角是 (90^\circ)。

因为：

[
x^Ty=|x||y|\cos\theta
]

所以内积为 0 时：

[
\cos\theta=0
]

---

## 正交和线性无关有什么关系？

**非零的两两正交向量一定线性无关。**

证明很简单。

如果：

[
a_1v_1+\cdots+a_nv_n=0
]

两边与 (v_k) 做内积：

[
a_kv_k^Tv_k=0
]

因为其他项都正交消失。

又因为：

[
v_k^Tv_k>0
]

所以：

[
a_k=0
]

所有系数都只能为 0。

---

# 正交矩阵

## 面试版回答

对于实方阵 (Q)，如果：

[
Q^TQ=QQ^T=I
]

那么称 (Q) 为正交矩阵。

因此：

[
Q^{-1}=Q^T
]

它的列向量组成一组**标准正交基**。

---

## 正交矩阵有什么意义？

它保持向量长度。

因为：

[
|Qx|^2
======

(Qx)^T(Qx)
]

[
=x^TQ^TQx=x^Tx
]

因此：

[
\boxed{|Qx|=|x|}
]

同时也保持角度。

所以正交变换通常对应：

* 旋转；
* 镜像反射；

而不会造成拉伸。

另外：

[
\det(Q)=\pm1
]

---

# 6. 高斯分布（正态分布）

这是这个题单里唯一一个偏概率统计的问题。

## 一维高斯分布

如果：

[
X\sim\mathcal N(\mu,\sigma^2)
]

概率密度为：

[
f(x)=
\frac{1}{\sqrt{2\pi}\sigma}
\exp
\left(
-\frac{(x-\mu)^2}{2\sigma^2}
\right)
]

其中：

[
\mu=E[X]
]

是均值，

[
\sigma^2=\operatorname{Var}(X)
]

是方差。

---

## 怎么给老师解释？

(\mu) 决定钟形曲线的**中心位置**。

(\sigma^2) 决定分布的**宽窄程度**：

* 方差小 → 数据集中；
* 方差大 → 数据分散。

---

# 多元高斯分布

机器学习面试更可能问这个。

[
x\sim\mathcal N(\mu,\Sigma)
]

其中：

[
\mu\in\mathbb R^n
]

是均值向量，

[
\Sigma\in\mathbb R^{n\times n}
]

是协方差矩阵。

密度函数：

[
p(x)=
\frac{1}
{(2\pi)^{n/2}|\Sigma|^{1/2}}
\exp
\left(
-\frac12(x-\mu)^T
\Sigma^{-1}
(x-\mu)
\right)
]

其中出现的：

[
(x-\mu)^T\Sigma^{-1}(x-\mu)
]

叫**马氏距离的平方**。

---

## 协方差矩阵为什么和线性代数有关？

[
\Sigma_{ij}
===========

\operatorname{Cov}(X_i,X_j)
]

对角线：

[
\Sigma_{ii}=\operatorname{Var}(X_i)
]

表示每一个维度的方差。

非对角元素表示两个变量之间的协方差。

同时：

[
\Sigma=\Sigma^T
]

而且协方差矩阵一定是：

[
\boxed{\text{半正定矩阵}}
]

因为对任意 (x)：

[
x^T\Sigma x\ge0
]

这就能自然接到第 7 题的正定矩阵。

---

# 7. 相似矩阵与正定矩阵

注意：

> **这是两个完全不同的概念。**

老师很可能故意把它们放一起问。

---

# 相似矩阵

如果存在可逆矩阵 (P)，使：

[
B=P^{-1}AP
]

那么称 (A,B) 相似。

---

## 相似意味着什么？

它们本质上表示：

> **同一个线性变换在不同基下面的矩阵表示。**

所以相似矩阵会共享很多性质。

例如：

[
\det(A)=\det(B)
]

[
\operatorname{tr}(A)=\operatorname{tr}(B)
]

并且有相同的：

* 特征多项式；
* 特征值；
* 行列式；
* 迹；
* 秩。

---

## 对角化其实就是相似变换

如果：

[
A=PDP^{-1}
]

那么：

[
P^{-1}AP=D
]

因此：

[
A\sim D
]

也就是说：

> A 能对角化，就是 A 与一个对角矩阵相似。

---

# 正定矩阵

对于实对称矩阵 (A)，如果对于任意非零向量：

[
x\neq0
]

都有：

[
x^TAx>0
]

则称 (A) 是正定矩阵。

记为：

[
A\succ0
]

---

## 最重要的等价条件

对于**实对称矩阵**：

[
A\succ0
]

等价于：

[
\boxed{\text{A的所有特征值都大于0}}
]

也等价于所有顺序主子式均大于 0：

[
\Delta_1>0,\Delta_2>0,\dots,\Delta_n>0
]

这叫 Sylvester 判据。

---

## 为什么机器学习里喜欢正定矩阵？

因为：

[
x^TAx
]

形成类似“碗形”的结构。

例如优化中的 Hessian：

如果：

[
\nabla^2f(x)\succ0
]

那么函数在这里局部严格凸。

---

## 千万不要混淆

相似变换：

[
P^{-1}AP
]

合同变换：

[
P^TAP
]

正定性与**合同变换**联系更加密切，而不是普通相似变换。

这个属于老师比较喜欢的追问。

---

# 8. 矩阵范数：一阶、二阶

先区分：

> **向量范数**和**矩阵范数**。

---

# 向量范数

对于：

[
x=(x_1,\dots,x_n)^T
]

### 1-范数

[
\boxed{
|x|_1
=====

\sum_{i=1}^n|x_i|
}
]

例如：

[
x=(1,-2,3)
]

那么：

[
|x|_1=6
]

---

### 2-范数

[
\boxed{
|x|_2=
\sqrt{
\sum_i x_i^2
}
}
]

即欧氏距离。

例如：

[
(3,4)
]

有：

[
|(3,4)|_2=5
]

---

### 无穷范数

顺便一定记住：

[
\boxed{
|x|_\infty=\max_i|x_i|
}
]

---

# 矩阵范数

这里老师可能故意追问。

对于：

[
A=(a_{ij})
]

矩阵诱导 1-范数：

[
\boxed{
|A|_1
=====

\max_j\sum_i|a_{ij}|
}
]

也就是：

> **绝对值列和的最大值。**

---

矩阵诱导无穷范数：

[
\boxed{
|A|*\infty=
\max_i\sum_j|a*{ij}|
}
]

即：

> **绝对值行和最大值。**

---

## 矩阵 2-范数

这个容易答错。

矩阵 2-范数不是“所有元素平方和再开根”。

真正的诱导 2-范数：

[
\boxed{
|A|_2
=====

\sigma_{\max}(A)
}
]

也就是：

> A 的最大奇异值。

等价于：

[
|A|_2
=====

\sqrt{
\lambda_{\max}(A^TA)
}
]

---

## 那元素平方和是什么？

这是 Frobenius 范数：

[
\boxed{
|A|_F
=====

\sqrt{
\sum_{ij}|a_{ij}|^2
}
}
]

而且：

[
|A|_F
=====

\sqrt{\sum_i\sigma_i^2}
]

面试时千万区分。

---

# 9. 特征值与特征向量

## 20 秒标准答案

对于方阵 (A)，如果存在非零向量 (v) 和标量 (\lambda)，满足：

[
Av=\lambda v
]

那么：

* (\lambda) 是 A 的特征值；
* (v) 是对应的特征向量。

其几何意义是：

> 经过线性变换 (A) 后，特征向量的方向保持不变，只发生长度伸缩，伸缩倍数就是特征值。

---

## 特征值怎么求？

由：

[
Av=\lambda v
]

得到：

[
(A-\lambda I)v=0
]

要存在：

[
v\neq0
]

必须使：

[
A-\lambda I
]

不是满秩矩阵。

因此：

[
\boxed{
\det(A-\lambda I)=0
}
]

这就是**特征方程**。

---

## 举例

[
A=
\begin{bmatrix}
2&0\
0&3
\end{bmatrix}
]

有：

[
Ae_1=2e_1
]

所以：

[
\lambda_1=2
]

以及：

[
Ae_2=3e_2
]

所以：

[
\lambda_2=3
]

---

## 两个必须会的结论

特征值之和：

[
\boxed{
\sum_i\lambda_i=\operatorname{tr}(A)
}
]

特征值之积：

[
\boxed{
\prod_i\lambda_i=\det(A)
}
]

计算重数也算进去。

---

## 对称矩阵有什么特殊性质？

如果：

[
A=A^T
]

那么：

1. 所有特征值都是实数；
2. 不同特征值对应的特征向量正交；
3. 一定可以正交对角化。

即存在正交矩阵：

[
Q^TQ=I
]

使：

[
\boxed{
A=Q\Lambda Q^T
}
]

这一点非常重要。

---

# 10. (Ax=b) 解的存在条件

这是线代面试最值得认真掌握的一题。

设：

[
A\in\mathbb R^{m\times n}
]

要求：

[
Ax=b
]

什么时候有解？

---

## 最标准答案

[
\boxed{
\operatorname{rank}(A)
======================

\operatorname{rank}([A|b])
}
]

时有解。

这叫：

> **Rouché–Capelli 定理（秩判据）。**

---

## 为什么？

把：

[
A=[a_1,a_2,\dots,a_n]
]

那么：

[
Ax=b
]

就是：

[
x_1a_1+x_2a_2+\dots+x_na_n=b
]

所以问题本质上是在问：

> (b) 能不能由 A 的列向量线性表示？

即：

[
\boxed{
b\in\operatorname{Col}(A)
}
]

---

# 三种情况一定会

设未知数有 (n) 个。

### 无解

[
\operatorname{rank}(A)
<
\operatorname{rank}([A|b])
]

说明 (b) 不在 A 的列空间里。

---

### 唯一解

[
\operatorname{rank}(A)
======================

\operatorname{rank}([A|b])
=n
]

---

### 无穷多解

[
\operatorname{rank}(A)
======================

\operatorname{rank}([A|b])
<n
]

存在：

[
n-r
]

个自由变量。

---

## 方阵情况特别简单

对于：

[
A\in\mathbb R^{n\times n}
]

如果：

[
\det(A)\neq0
]

那么：

[
A^{-1}
]

存在。

因此任意 (b) 都有唯一解：

[
\boxed{x=A^{-1}b}
]

不过实际数值计算一般不会真的显式求逆来解方程。

---

# 11. 张量与矩阵区别

这个问题如果是 AI/深度学习老师，非常可能问。

## 面试版回答

从机器学习的常用表示来看：

* 标量：0 阶张量；
* 向量：1 阶张量；
* 矩阵：2 阶张量；
* 三维及以上数组：高阶张量。

因此：

> **矩阵可以看作二阶张量，而张量是更一般的概念。**

---

例如：

标量：

[
x=3
]

向量：

[
x_i
]

矩阵：

[
A_{ij}
]

三阶张量：

[
T_{ijk}
]

---

## 深度学习例子

一张 RGB 图片通常表示成：

[
H\times W\times C
]

就是三维张量。

一批图片：

[
B\times C\times H\times W
]

就是四维张量。

Transformer 中 hidden state 可能是：

[
B\times L\times D
]

也是三维 tensor。

---

## 但数学上要严谨一点

如果老师是数学老师，不要只说：

> “Tensor 就是多维数组。”

更准确的说法是：

> 张量本质上是满足特定坐标变换规律的多线性对象，多维数组只是选定一组基以后张量的坐标表示。

不过对于深度学习语境，PyTorch 的：

```python
torch.Tensor
```

实际上更接近：

> N 维数组数据结构。

所以可以按老师的语境调整回答。

# 12. 笛卡尔积、内积、外积

这三个一定要彻底区分。

---

# 一、笛卡尔积 Cartesian Product

对于两个集合：

[
A,B
]

它们的笛卡尔积：

[
\boxed{
A\times B
=========

{(a,b)\mid a\in A,b\in B}
}
]

产生的是**有序对集合**。

例如：

[
A={1,2}
]

[
B={a,b}
]

则：

[
A\times B
=========

{(1,a),(1,b),(2,a),(2,b)}
]

---

对于向量空间：

[
\mathbb R^m\times\mathbb R^n
]

本质就是：

[
\mathbb R^{m+n}
]

所以：

[
\dim(V\times W)
===============

\dim V+\dim W
]

---

# 二、内积 Inner Product

欧氏空间中：

[
x,y\in\mathbb R^n
]

有：

[
\boxed{
\langle x,y\rangle=x^Ty
}
]

结果是：

[
\boxed{\text{一个标量}}
]

例如：

[
x=
\begin{bmatrix}
1\2
\end{bmatrix},
\quad
y=
\begin{bmatrix}
3\4
\end{bmatrix}
]

那么：

[
x^Ty=1\times3+2\times4=11
]

---

## 内积有什么意义？

可以用来计算：

### 长度

[
|x|_2=\sqrt{x^Tx}
]

### 夹角

[
\cos\theta=
\frac{x^Ty}{|x||y|}
]

### 正交

[
x^Ty=0
]

所以内积在几何上非常重要。

---

# 三、外积 Outer Product

假设：

[
x\in\mathbb R^m
]

[
y\in\mathbb R^n
]

那么：

[
\boxed{
xy^T
}
]

得到：

[
m\times n
]

矩阵。

例如：

[
x=
\begin{bmatrix}
1\2
\end{bmatrix},
\qquad
y=
\begin{bmatrix}
3\4\5
\end{bmatrix}
]

则：

[
xy^T
====

\begin{bmatrix}
1\2
\end{bmatrix}
\begin{bmatrix}
3&4&5
\end{bmatrix}
]

# [

\begin{bmatrix}
3&4&5\
6&8&10
\end{bmatrix}
]

---

## 外积一个极重要性质

对于非零 (x,y)：

[
\boxed{
\operatorname{rank}(xy^T)=1
}
]

因为所有列实际上都是 (x) 的倍数。

这与机器学习中的**低秩分解、LoRA**都能联系起来。

例如 LoRA：

[
\Delta W=BA
]

本质就是利用低秩矩阵来表达参数更新。

---

# 三者一口气区分

假设：

[
x,y\in\mathbb R^n
]

你在面试里可以直接说：

| 运算   | 表达          | 输出       |
| ---- | ----------- | -------- |
| 笛卡尔积 | (A\times B) | 有序对组成的集合 |
| 内积   | (x^Ty)      | 标量       |
| 外积   | (xy^T)      | 矩阵       |

另外千万不要把**笛卡尔积**和**叉积（cross product）**弄混。

叉积是：

[
a\times b
]

通常讨论 (\mathbb R^3)，结果还是一个向量，并且垂直于 (a,b)。

---

# 最后，把这 12 题串起来

这其实不是 12 个完全独立的问题，而是一整套知识链：

[
\boxed{
\text{线性空间}
\rightarrow
\text{基}
\rightarrow
\text{线性无关}
\rightarrow
\text{矩阵秩}
}
]

矩阵本质上描述一个：

[
\boxed{\text{线性映射}}
]

而：

[
Ax=b
]

是在问：

[
b\text{ 是否属于 }A\text{ 的列空间}
]

于是出现：

[
\operatorname{rank}(A)
======================

\operatorname{rank}([A|b])
]

另一方面，对于线性变换：

[
Av=\lambda v
]

寻找的是变换中方向不发生变化的向量，也就是：

[
\boxed{\text{特征向量}}
]

如果矩阵是实对称矩阵，则可以找到一组标准正交特征向量：

[
A=Q\Lambda Q^T
]

而如果所有：

[
\lambda_i>0
]

则：

[
A\succ0
]

成为正定矩阵。

这也是为什么**秩、基、特征值、正交、正定**这些概念最后都会连成一张网。

---

# 保研面试我建议你至少背熟这 10 句话

1. **秩是矩阵线性无关行或列的最大个数，也是列空间/行空间的维数。**
2. **满秩意味着 rank 达到了 (\min(m,n))。**
3. **线性无关意味着只有全零系数才能得到零向量。**
4. **基是既线性无关又能张成整个空间的一组向量。**
5. **正交向量内积为 0，正交矩阵满足 (Q^TQ=I)。**
6. **相似矩阵满足 (B=P^{-1}AP)，表示同一个线性变换在不同基下的表示。**
7. **正定矩阵满足 (x^TAx>0)，实对称情况下等价于全部特征值大于 0。**
8. **特征向量满足 (Av=\lambda v)，线性变换后方向不变。**
9. **(Ax=b) 有解当且仅当 (b) 属于 A 的列空间，也就是 (\operatorname{rank}(A)=\operatorname{rank}([A|b]))。**
10. **内积得到标量，外积得到矩阵；矩阵可以看作二阶张量。**
